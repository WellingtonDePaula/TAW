# 🌐 Tópicos Avançados em Web

Repositório com exercícios e projetos desenvolvidos durante a disciplina de **Tópicos Avançados em Web**.

## 🛠️ Tecnologias

- JavaScript
- React

## 📁 Estrutura

```
TAW/
├── exercicios/   # Listas de exercícios
└── projetos/     # Projetos e trabalhos
```

## ▶️ Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/WellingtonDePaula/TAW.git
   ```

2. Instale as dependências (para projetos React):
   ```bash
   npm install
   ```

3. Inicie a aplicação:
   ```bash
   npm start
   ```
